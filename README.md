### 🧠 Featured Projects

**[Engram](https://github.com/Agentscreator/engram-memory)**, ⭐ 82, Top Contributor
Multi-agent memory consistency platform. 90+ merged PRs and 130+ commits, including PII/secret-scanning security hardening and critical fixes to the conflict-detection engine. Also shipped the CLI, dashboard, and Neovim/Slack plugins. Real collaboration in a production codebase with an outside team, not a solo repo.
🔗 [repo](https://github.com/Agentscreator/engram-memory) · [site](https://www.engram-memory.com/)

**[Messengers of Hope](https://github.com/ismaeldouglasdev/mensageiros-da-esperanca)**, NGO management system
Course registration, digital attendance, and a real-time dashboard (Firebase) for 100+ volunteers. Full lifecycle for a real client: discovery, build, handoff, and a testimonial from the institution.
🔗 [repo](https://github.com/ismaeldouglasdev/mensageiros-da-esperanca) · [live](https://mensageiros-da-esperanca.vercel.app/)

**Elshaday, Omnichannel Retail Integration**, commercial project (private code)
Event-driven service syncing a physical POS (OSPOS/MySQL) with WooCommerce, Shopee, and Mercado Livre. CDC agent, Saga pattern, inventory sync across marketplace adapters. Architecture available to walk through in a call.

**[provider-health-daemon](https://github.com/ismaeldouglasdev/provider-health-daemon)**, LLM routing infrastructure
Real-time, error-aware routing daemon for a self-hosted multi-provider gateway (9router). Cooldown management, exponential backoff, prompt-limiting. Keeps agentic pipelines running when a provider fails or throttles.

**[amd-hybrid-router](https://github.com/ismaeldouglasdev/amd-hybrid-router)**, 🏆 AMD Hackathon Act II (Track 1)
Cost-aware routing agent that picks the cheapest Fireworks AI model sufficient for each task, built under hackathon time constraints.

**[plexo](https://github.com/ismaeldouglasdev/plexo)**, task manager with three interfaces
One domain model exposed through a Web UI (React), a Terminal UI (Textual), and a REST API. Fully local, plain JSON storage, no external dependencies.

**[PeakVault](https://github.com/ismaeldouglasdev/PeakVault)**, generic JSON tracker (CustomTkinter)
Dynamic CRUD that adapts to any flat JSON structure. Handles 10k+ record imports, grouping, and chart generation.
